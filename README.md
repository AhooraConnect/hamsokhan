## نکته مهم
چون این پروژه روی GitHub Pages اجرا می‌شود، اطلاعات ورود داخل JavaScript قابل مشاهده‌اند. همچنین PeerJS برای سیگنالینگ استفاده شده است. برای استفاده‌ی کاملاً خصوصی و حرفه‌ای باید احراز هویت و سرور سیگنالینگ/بک‌اند اختصاصی اضافه شود.

## انتشار روی GitHub Pages
1. فایل‌های این پوشه را داخل یک repository قرار بده.
2. در Settings → Pages، گزینه‌ی `Deploy from a branch` را انتخاب کن.
3. Branch را `main` و Folder را `/ (root)` بگذار و Save کن.
4. چند دقیقه صبر کن تا سایت منتشر شود.

GitHub Pages فایل‌های HTML/CSS/JS استاتیک را مستقیماً از repository منتشر می‌کند.
